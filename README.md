## Questionário

Qual é a diferença entre Working Directory, Staging Area e Repository?
WD é onde os arquivos sao editados

SA é onde fica as mudanças do git add, pra virar commit

repository é o histórico de commits  salvo 

Qual é a diferença entre git commit e git push?
o commit grava um ponto de versão, o push joga pro remoto

É possível realizar vários commits antes de executar um git push? Explique.
sim se quiser das pra fazer o projeto inteiro antes de jogar para o remoto, so nao é recomendado

Por que é interessante realizar commits pequenos e descritivos?
para rstrear o codigo, e evitar perda de progresso com o apagao

O que acontece com os commits locais quando ainda não executamos o git push?
ficam salvos localmente, nao no remoto

Como verificar, pelo GitHub, se os commits foram enviados corretamente?
vendo a aba de commits, e com o git log.
